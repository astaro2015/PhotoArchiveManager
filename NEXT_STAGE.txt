НОВОЕ В 1.7.1:
1. «Похожие / копии»: у каждого кадра есть `Оставить` + `в карантин`; допускается несколько keepers. Финальный карантин проверяет все keepers и только отдельно отмеченные candidates.
2. Правый клик по выбранным элементам дублирует применимые действия правой панели. Extended-selection не схлопывается, если щёлкнуть правой кнопкой по уже выделенной строке.
3. Контекстные меню: Библиотека, точные дубли, похожие, серии, люди, события, хронология, организация, карантин.
4. Финальные физические действия выделены красным.
5. О программе: разработчик Привалов Олег; версия 1.7.1; дата создания проекта 01.09.2026.

СОХРАНЕНО ИЗ 1.7.0:
- папки Организации: год → русское сокращение месяца/месяцев + ручное событие, без цифровых префиксов и диапазона дней;
- имя файла: YYYY-MM-DD_исходное имя — подтверждённые именованные люди.ext, без времени;
- исходное имя не наслаивается при повторной организации;
- Preview/Execute используют один TargetPath; SHA-256, no-overwrite, cross-volume copy→verify→delete и Undo сохранены.
